# notebook

Проблемы с управлением вентиляторами на ноутбуках Tecno в Linux часто связаны с отсутствием специфической поддержки EC (Embedded Controller) в ядре. Решения включают использование универсальных утилит типа
fan-control, настройку lm-sensors, проверку параметров ядра или корректировку настроек в BIOS. 
Основные способы решения:
```
    Утилиты управления: Попробуйте установить Fan Control (io.github.wiiznokes.fan-control) через Flathub. Для работы может потребоваться добавление udev-правила.
    Диагностика (lm-sensors): Установите lm-sensors, запустите sudo sensors-detect (отвечайте "yes" на большинство вопросов, особенно про EC) и проверьте, видит ли система датчики и вентиляторы.
    BIOS/UEFI: Проверьте настройки в BIOS в разделе Power/Hardware Monitor, чтобы изменить интеллектуальный режим работы (Smart Fan).
    Параметры ядра: Иногда помогает добавление параметров acpi_enforce_resources=lax или специфических параметров для моделей ноутбуков в /etc/default/grub (требует осторожности).
    Альтернативные дистрибутивы: Убедитесь, что используете современную версию ядра Linux, так как поддержка новых ноутбуков улучшается в новых релизах. 
```
Если управление по-прежнему недоступно, проблема может заключаться в закрытом протоколе EC конкретной модели Tecno.
